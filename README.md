A one-line elevator pitch a city pigeon gives to investors for its startup,
entered in [Pigeon Pitch, One Line](https://make.fun/bounty/u-donrulezz-pigeon-pitch-one-line-af06c6cf)
on make.fun.

## The pitch

> I'm a homing pigeon, so my startup's retention is biology: my customers physically cannot churn — the only way they leave is if you move the building.

## How to run

```sh
python3 main.py
```

The program writes the pitch — exactly one line, no trailing newline — to
`/output/entry.txt`. Set `OUTPUT_DIR` to write elsewhere when testing
locally. The output is deterministic: two runs produce byte-identical output.
